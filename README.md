# shopping-list: רשימת קניות מהקבלות שלך

מעלים כמה קבלות מהסופר, ו-Claude בונה לכם רשימת קניות אישית לפי מחלקות בחנות: מה קונים כל שבוע, כמה זה עולה בערך, ושני מצבים: **מה חסר בבית** ו**בחנות**. אפשר לשתף עם בן או בת זוג.

הקבלות נקראות במחשב שלכם. הרשימה נשמרת בחשבון ה-Claude שלכם, והיא לא ציבורית.

## איך מתחילים (הדרך הקלה)
1. צריך את אפליקציית Claude במחשב, עם לשונית **Code**. ייתכן שנדרש מנוי בתשלום.
2. בלשונית Code מדביקים את המשפט הזה ושולחים:

> תתקין לי את הסקיל מהקישור הזה: https://github.com/shanyrollinks/shopping-list ואז תבנה לי רשימת קניות מהקבלות שלי.

3. מעלים 4 עד 6 קבלות. הכי קל עם קבלות דיגיטליות (PDF) שמגיעות במייל או באפליקציה של הסופר. אם יש רק קבלות נייר, מצלמים ושולחים לעצמכם למחשב (למשל בוואטסאפ ווב). עונים על כמה שאלות, ואם מופיעה בקשת אישור, לוחצים אפשר.

הודעה מוכנה לשליחה בוואטסאפ נמצאת ב-`INSTALL-MESSAGE.md`.

## עדכון לגרסה חדשה
הגרסה הנוכחית כתובה בקובץ `VERSION`. כדי לעדכן, כותבים ל-Claude: "תעדכן את הסקיל shopping-list מהמאגר". רשימות שכבר נבנו לא משתנות; העדכון משפיע רק על רשימה חדשה.

## למפתחים
```
git clone https://github.com/shanyrollinks/shopping-list ~/.claude/skills/shopping-list
```
דורש python3. הסקריפט `scripts/shopping.py` מאחד קבלות (`aggregate`) ובונה את הדף מתבנית (`render`).

בדיקה מהירה שהכול עובד: `python3 tests/run.py`.
